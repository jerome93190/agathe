      Synchro entre appareils

      Tes notes sont synchronisées automatiquement dans les 2 sens entre tes appareils, via un Gist GitHub privé (ta sauvegarde). Méthode fiable : un code à coller une fois par appareil.

      Non synchronisé
      Comment obtenir ce code GitHub ? (1 min)
      1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic).
      2. « Generate new token (classic) », coche la case gist, puis génère-le.
      3. Copie le code (il commence par ghp_) et colle-le ci-dessus.
